Pulso

Monitor de recursos por aplicación para GNOME · 0.1.0 beta 2

Requisitos: distribución con apt y libadwaita 1.5+ — Ubuntu 24.04 o posterior, Linux Mint 22, Pop!_OS 24.04, Debian 13 o posterior. ¿Usas Arch o CachyOS? Instálalo desde el AUR: paru -S pulso.

Instalar

En una terminal (Ctrl + Alt + T), uno por uno:

sudo wget -qO /usr/share/keyrings/pulso-archive-keyring.gpg https://ariot117.github.io/pulso/pulso-archive-keyring.gpg
printf 'Types: deb\nURIs: https://ariot117.github.io/pulso\nSuites: ./\nSigned-By: /usr/share/keyrings/pulso-archive-keyring.gpg\n' | sudo tee /etc/apt/sources.list.d/pulso.sources
sudo apt update
sudo apt install pulso

Ábrelo desde Actividades buscando «Pulso». Las actualizaciones llegan con sudo apt upgrade.

Desinstalar

sudo apt remove pulso
sudo rm /etc/apt/sources.list.d/pulso.sources /usr/share/keyrings/pulso-archive-keyring.gpg
