Pulso

Monitor de recursos por aplicación para GNOME · 0.1.0 beta 1

Requisitos: Ubuntu 24.10 o posterior (o Debian equivalente) con GTK 4.14+ y libadwaita 1.6+.

Instalar

sudo curl -fsSL https://ariot117.github.io/pulso/pulso-archive-keyring.gpg -o /usr/share/keyrings/pulso-archive-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/pulso-archive-keyring.gpg] https://ariot117.github.io/pulso ./" | sudo tee /etc/apt/sources.list.d/pulso.list
sudo apt update
sudo apt install pulso

Las actualizaciones llegan con sudo apt upgrade.

Desinstalar

sudo apt remove pulso
sudo rm /etc/apt/sources.list.d/pulso.list /usr/share/keyrings/pulso-archive-keyring.gpg
